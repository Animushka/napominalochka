Личный бот-напоминалка с Mini App внутри Telegram. Задавай время и расписание,
получай напоминания до подтверждения, откладывай дела и выбирай удобный язык.

## Возможности

- Русский и английский интерфейсы, сохранение выбранного языка.
- Создание, редактирование и удаление напоминаний через Mini App или чат.
- Разовые, ежедневные, по будням, еженедельные, ежемесячные и ежегодные расписания.
- Повторы до «Готово» с интервалом 1, 5, 10, 20, 30 или 60 минут; по умолчанию 10.
- «Отложить» на 10 минут, час или до следующего утра.
- Необязательная однократная контрольная проверка через 20 минут после «Готово».
  Бот спрашивает, всё ли точно сделано.
- Часовые пояса, экспорт календаря и восстановление очереди после перезапуска.
- Один контейнер, SQLite и проверка подлинности Telegram Mini App initData.

## Своя установка

Нужны Docker Compose, токен собственного Telegram-бота и HTTPS-домен для Mini App.

```sh
cp .env.example .env
# Заполни TELEGRAM_BOT_TOKEN и WEB_APP_URL только в локальном .env.
mkdir -p data
sudo chown 10001:10001 data
docker compose up -d --build
docker compose ps
```

Приложение слушает `127.0.0.1:8097`; пример HTTPS-прокси —
[Caddyfile.example](Caddyfile.example). Данные хранятся в `data/`; перед
обновлением сохраняй согласованную резервную копию SQLite. Токен, `.env`,
рабочая база и журналы исключены из Git. Публичный репозиторий не содержит
реквизитов работающего экземпляра.

Команда `/start` открывает меню, `/language ru` и `/language en` переключают язык.
Настройки повторов и контрольной проверки доступны в Mini App. Для оформления
своего бота есть `ops/configure_bot.py`: он читает `TELEGRAM_BOT_TOKEN` из окружения,
применяет RU/EN описания из `ops/bot-profile.json` и устанавливает аватар.

## Алиса: персональное подключение сценариев

Необязательная интеграция использует официальный API умного дома Яндекса. Каждый
пользователь связывает собственный аккаунт и выбирает один свой сценарий. Колонка
произносит заранее заданную в «Доме с Алисой» фразу; текст напоминания не передаётся
в Яндекс. Запускается весь выбранный сценарий со всеми его действиями.

Для включения оператор регистрирует OAuth-приложение **«Для авторизации пользователей»**
с правами `iot:view` и `iot:control`, веб-платформой и Redirect URI
`https://ВАШ-ДОМЕН/integrations/yandex/callback`. Укажите `YANDEX_CLIENT_ID`,
`YANDEX_CLIENT_SECRET` и постоянный `YANDEX_TOKEN_KEY` (32 случайных байта в hex)
в закрытом `.env`, затем пересоздайте контейнер. Без этих параметров раздел скрыт.
Секреты не передаются в Mini App. Страница `/privacy` объясняет обработку данных.

Пользователь создаёт сценарий с действием «Прочитать текст вслух», начинает подключение
в Mini App и проходит вход на сайте Яндекса. Кнопка «Подтвердить в Telegram» завершает
привязку только для того Telegram-аккаунта, который начал вход. Затем пользователь
сохраняет выбранный сценарий, проверяет его и отдельно включает озвучку.

- Озвучка выключена по умолчанию и происходит один раз при наступлении напоминания.
- Повторы, откладывание и контрольное сообщение через 20 минут остаются в Telegram.
- На аккаунт допускается один запуск в минуту. Очередь старше 5 минут пропускается.
- При неопределённом ответе на запуск повторов нет, озвучка выключается до проверки.
  Telegram продолжает работать независимо от Яндекса.
- Отключение и `/unregister` удаляют сохранённые токены и очередь; уже отправленную
  команду отозвать нельзя. Для полного отзыва разрешения используйте настройки Яндекс ID.
- OAuth state/PKCE и подтверждение привязки одноразовые. Токены зашифрованы AES-256-GCM.
  Ключ хранится отдельно от базы; его нужно включать в защищённую резервную копию.

Интеграция проверяется mock HTTP-тестами. Успешный HTTP-ответ не доказывает фактическую
озвучку на устройстве; после настройки нужен тест с собственным аккаунтом и колонкой.
